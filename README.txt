TownTrade SA Marketplace
Project Description

TownTrade SA is a consumer-to-consumer e-commerce marketplace developed using PHP and MySQL.

Technologies Used
HTML5
CSS3
Bootstrap
JavaScript
PHP
MySQL
XAMPP
Features
User Registration & Login
Product Listings
Product Management
Shopping Cart
Checkout
Reviews & Ratings
Admin Dashboard
Installation Instructions
Copy project folder into xampp/htdocs/
Start Apache and MySQL in XAMPP
Import database into phpMyAdmin
Open:
http://localhost/towntrade/
